# Immutable pre-upgrade crypto data

Synthetic public passwords, keys and payloads, generated by the unchanged old
implementation at `6a0530638c5839ed19893a16fca3a4b890af8d4e` and its original
locked crypto dependencies. These bytes are deliberately not generated by the
candidate under test.

Producer: [online run 38722316964](https://github.com/taichuy/1flowbase/actions/runs/38722316964).
`provenance.json` records the producer commit, source and lock hashes, fixture
hash and every resolved external package/checksum. The original lock remains in
Git; both exact locks are also attached to that run. The producer rejects any
external package absent from the old lock before compilation/execution.

Actual owner tests consume these fixed bytes for password authentication,
provider-secret decryption, password-protected backup recovery/envelope/manifest
authentication and trusted artifact signature verification. Correct-password/key
positives and wrong-password/key, context and tamper negatives are required.
Do not replace this fixture with a current-library roundtrip when updating tests.
