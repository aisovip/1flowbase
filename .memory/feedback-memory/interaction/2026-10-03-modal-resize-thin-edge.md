弹窗左右调宽手柄用细边缘线呈现，悬停高亮；不要显示粗条。透明命中区域可以保留较宽，兼顾拖拽易用性。

共享抽屉壳也遵循此规则：边缘显示 1px 细线，悬停和拖动只变色；在共享壳层统一处理，不在通知等消费者各自覆写。

原因：用户在 MCP Tool 编辑弹窗验看后指出粗绿色条过重，明确要求细化成边缘线。

2026-10-14 23：用户在通知抽屉再次指出粗绿色拖拽条过重，明确要求从共享抽屉壳层统一细化，只改变线的颜色。

适用：弹窗双侧与共享抽屉 resize 手柄的视觉与交互设计。
