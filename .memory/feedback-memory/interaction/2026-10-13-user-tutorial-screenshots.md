- 规则：用户要求操作本地浏览器截图并编写教程时，将实际界面截图插入教程对应步骤，附说明，并验证发布后图像可加载。不能仅把截图用于内部核对后交付纯文字教程。
- 原因：用户在 Agent Logs Wiki 教程交付后明确指出没有图示，截图要求未被落实到公开文档。
- 适用场景：安装、配置、操作教程及 Wiki 的图文交付；截图可裁取目标界面，使用合成日志，避免暴露真实密钥和私人正文。
